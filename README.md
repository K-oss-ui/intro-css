# Introdução ao CSS

Neste repositório, abordamos os principais conceitos necessários para começar a estililar pagínas **HTML** e compreender como o navegador interpreta e aplica regras de estilo.

## O que é o CSS?
**CSS (Cascading Style Sheets)** é a Linguagem utilizada para definir a apresentação visual dos elementos *HTML*  

## Formas de aplicar o CSS
- CSS Inline
- CSS Interno
- CSS Externo
